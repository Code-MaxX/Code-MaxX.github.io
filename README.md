# Sahil Ghule — Portfolio

Personal portfolio for **Sahil Dilip Ghule** (Backend & AI Systems Engineer).

## Run locally

```bash
cd ~/Desktop/sahil-ghule-portfolio
python3 -m http.server 5173
```

Open [http://localhost:5173](http://localhost:5173).

## Deploy (GitHub Pages)

1. Create a repo (e.g. `Code-MaxX.github.io` for `https://code-maxx.github.io`).
2. Push these files to `main`.
3. Enable **Settings → Pages → Deploy from branch → main / root**.

Or use any static host (Vercel, Netlify, Cloudflare Pages) — point at this folder.
